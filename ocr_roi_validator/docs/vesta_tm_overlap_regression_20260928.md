# TM 및 겹친 OCR 박스 회귀 수정

## 재현 자료

- 이전 성공 실행: `20260928_185612_242405/results_185619_508697.json`
- 최신 실패 실행: `20260928_232026_379128/results_232101_265656.json`
- 두 실행의 TC3 ROI1과 TC7 ROI2를 조사했다.
- 최신 공통 캡처 기준은 319×240, 이전은 320×240이다. 캡처 영역과 리사이즈가 입력 영상을 바꾼 것은 확인했지만, 리사이즈만이 두 오류의 원인이라는 인과관계까지 입증한 것은 아니다.

## 변경

### TM 위첨자

기존 검출 박스 기준을 통과하면 기존 동작을 유지한다. 높이·폭·점수·위쪽 위치 조건을 만족하나 박스 겹침 때문에 인접 조건만 실패할 때, 실제 OCR 입력의 픽셀을 추가 검사한다.

- 박스 겹침은 위첨자 박스 너비의 절반 이하여야 한다.
- 두 이진화 기준에서 본문과 위첨자 사이 빈 열이 확인돼야 한다. 리사이즈로 생기는 흐린 테두리 대신 전경을 기준으로 검사한다.
- 실제 글자 경계에도 기존 높이 비율 0.7, 폭 비율 1, 거리 비율 0.35, 위쪽 위치와 기준선 상승 조건을 적용한다.
- 근거가 없거나 모호하면 변환하지 않는다. 정답 문자열을 입력으로 받지 않는다.
- 원래 박스와 `raw_text`를 유지하고, `pixel_separation`에 실제 픽셀 경계를 남긴다. 추가 OCR 호출은 없다.

TM 투표나 최종 PASS 조건은 바꾸지 않았다. 일반 높이의 TM을 일괄 변환하거나 한 번 확인된 위첨자를 다른 프레임에 복사하지 않는다.

### `OK para a introducir.`

최신 OCR은 `OK para`와 `a introducir.` 두 박스를 반환했다. 박스가 15픽셀 겹쳤으며 단순 결합으로 `a`가 중복됐다.

- 같은 줄의 고신뢰 두 박스가 일부 겹치고, 왼쪽 끝과 오른쪽 첫 토큰의 문자가 중복될 때만 추가 검사한다.
- 두 박스를 합친 이미지 영역을 Rapid 인식기로 한 번 읽는다. 검출 단계는 다시 실행하지 않는다.
- 인식 점수가 0.9 이상이고, 실제 재인식 결과가 경계 중복만 제거한 문자열과 일치할 때만 채택한다.
- 다른 문자가 바뀌거나 원래 중복 문자열이 다시 읽히면 보정하지 않는다. 정답 문자열을 참조하지 않는다.
- `raw_text`와 원래 박스는 유지하며 `overlap` 진단에 이미지 영역, 재인식 문자열·점수·시간을 남긴다.
- 직접 ROI와 context 경로 모두 요청당 추가 인식은 최대 1회다. context 경로는 ROI 박스를 추린 후에만 실행한다. 기존 자동화 30초 감시 제한이 적용된다.
- 이 보완은 Rapid용이다. Paddle은 원래 결과를 유지한다.

## 실제 OCR 재실험

같은 현재 엔진으로 이전·최신 저장 화면 총 8개를 재생했다. Rapid 기본 모델, 직접 ROI 경로, margin 8/min_side 160/패딩·확대 설정을 사용했다. 당시 모든 입력과 모델 설정이 보존된 것은 아니므로 Vesta 전체 실행 재현으로 보지 않는다.

| 자료 | 원문 | 보정 결과 |
| --- | --- | --- |
| 이전 TC3 마지막 화면 | `ezDispense TM Limpieza` | `ezDispense™ Limpieza` |
| 최신 TC3 마지막 화면 | `zDispense TM Limpieza` | `zDispense™ Limpieza` |
| 이전 TC7 첫·마지막 화면 | `OK para introducir.` | 그대로 유지 |
| 최신 TC7 첫·마지막 화면 | `OK para a introducir.` | `OK para introducir.` |

TC3 첫 화면은 TM이 보이지 않아 양쪽 모두 기존 문자열을 유지했다. 최신 TC3 마지막 화면의 픽셀 검사에서 본문·위첨자 간격은 두 기준 모두 2픽셀이다. 최신 TC7 전체 ROI 요청은 첫 화면 1.296초, 마지막 화면 1.391초였다. 별도 실험의 추가 한 줄 인식은 약 0.09~0.22초였으며 일반적인 속도를 보장하는 수치는 아니다.

원문·보정·진단·입력 해시는 `captures/replay_tm_overlap_20260928.json`에 저장했다.

```powershell
.venv/Scripts/python.exe scripts/replay_vesta_regressions.py captures/automation/20260928_185612_242405/results_185619_508697.json captures/automation/20260928_232026_379128/results_232101_265656.json --output captures/replay_tm_overlap_20260928.json
```

## 검증과 한계

- UTF-8 환경 전체 테스트 631개 통과.
- 회귀 테스트: 픽셀 간격으로 박스 겹침 구분, 밝은/어두운 배경, 붙은 글자·빈 이미지 거부, 원문·박스 보존, 실제 반복 문자 보존, 낮은 신뢰도·다른 문자열 거부, context 추가 호출 중복 방지, 시간 초과 전달.
- 수정 후 Vesta 전체 자동 실행은 수행하지 않았다. 스크롤 전체 조립과 실제 TC 통과 여부는 다시 확인해야 한다.
- 사용자 Excel·프리셋·`lite`, 동기 캡처, 기존 30초 제한은 변경하지 않았다. 커밋·push하지 않았다.
